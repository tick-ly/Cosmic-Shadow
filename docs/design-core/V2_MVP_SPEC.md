# 《宇宙之影》V2 MVP 规格

更新时间：2026-07-02

## 目标

V2 首版只验证一条 5 分钟战术任务闭环：

进入任务 -> 选择单位 -> 沿节点移动 -> 到达目标节点 -> 使用风险技能推进目标 -> 移动到撤离点 -> 胜利或失败结算。

## 输入

- `TacticalMissionSO`：任务名、类型、时限、警戒上限、目标进度、目标节点、撤离节点、节点图、起始单位。
- `NodeMapSO`：节点、地形、归属、危险度、路线。
- `UnitDataSO`：单位领域、编制、生命、移动范围、技能列表。
- `SkillDataSO`：成功率、现实债务、反噬伤害、疲劳、冷却、失败警戒、成功目标进度。

## 输出

- HUD 显示任务状态、时间、警戒、目标进度、选中单位和最近日志。
- 风险面板显示目标节点、单位状态、技能成功率和风险等级。
- 任务状态输出为 `Running`、`Victory` 或 `Failed`。

## 胜负条件

- 胜利：目标进度达到要求，且至少一个存活单位位于撤离节点。
- 失败：所有单位失去战斗能力。
- 失败：警戒值达到或超过上限。
- 失败：任务时间达到或超过时限。
- 目标完成但未撤离时，不判定胜利。

## 首版暂不做

- 正式美术和动画。
- 存档读写。
- 复杂 AI。
- 大战略长线系统。
- 战地式大地图、载具、联网和流式加载。
- 旧 `UnityProject/` 代码迁移。
